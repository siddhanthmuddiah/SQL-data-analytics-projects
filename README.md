The project has two parts, and the scripts follow them:

- **Exploratory data analysis**, scripts `01` to `06`: you get to know the data, from the tables and dates to the big numbers and the top performers.
- **Advanced analytics**, scripts `07` to `13`: you go deeper with trends, running totals, performance, part-to-whole and segments. Two reports close the project, one for customers and one for products.

---
## 📌 Project Overview

This repository showcases an end-to-end SQL data analytics project built in **T-SQL (SQL Server)** to extract actionable business insights from relational sales data. Structured across 13 modular scripts, the workflow progresses from foundational **Exploratory Data Analysis (EDA)**—examining schemas, dimensions, and core metrics—to **Advanced Analytics**, including time-series trends, cumulative running totals, year-over-year performance comparisons, part-to-whole analysis, and customer/product segmentation. The project concludes with reusable SQL reporting views designed for business intelligence consumption.

---
### 🛠️ Tech Stack & Key Concepts
* **Database & Language:** SQL Server, T-SQL (CTEs, Window Functions, Subqueries, Aggregations, Views)
* **Dataset:** Star-schema sales dataset stored in CSV format inside the `Dataset/` directory
* **Repository Structure:**
  * `Dataset/` – Source CSV files used to populate the analytical tables
  * `b_scripts/` – 13 sequential T-SQL scripts (`01`–`06` for EDA, `07`–`13` for Advanced Analytics & Reporting)
